# DMMHS Dashboard

## Full Platform (RECOMMENDED — login, CRUD, branding, exports)

**File:** `DMMHS_Platform.html`

**Login:** Username `DMMHS` · Password `2026`

Features: school logo branding, localStorage database, CRUD, dark/light mode, PDF/Excel export, 4 analytics types, Chart.js, mobile responsive.

**Also requires:** `css/`, `js/`, `assets/dmmhs-logo.png` in the same folder.

## Analytics Dashboard (4 analysis types, no login)

**File:** `DMMHS_Analytics_Dashboard.html`

1. Double-click to open in Chrome or Edge
2. **6 tabs:** Overview · Descriptive · Diagnostic · Predictive · Prescriptive · Data Explorer
3. **Predictive:** enrollment forecasts, risk index by grade, intervention scenario slider
4. **Prescriptive:** priority matrix, 8 linked actions, impact/effort chart

## Complete Dashboard (all KPIs & charts)

**File:** `DMMHS_Complete_Dashboard.html`

- 7 tabs, 12 KPIs, 20+ charts, filters, recommendations

## Standard Dashboard

**File:** `DMMHS_Dashboard.html` — lighter 3-tab version

No install required. Internet needed once for Chart.js CDN.
